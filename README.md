# Dōjutsu Evolution

Epic pure HTML/CSS/JS animation of the Sharingan evolution:

**1 Tomoe → 2 Tomoe → 3 Tomoe → Itachi → Sasuke → Madara → Obito → Rinnegan**

## Features
- Sharp almond-shaped eyes
- Deep multi-layer irises with radial fibers
- Character-specific Mangekyō patterns
- Dark imposing auras
- Particle bursts & screen shake on transitions
- Alive micro-movements (breathing + gaze)
- Fully responsive

## Usage
Just open `index.html` in a browser.

Click anywhere after the sequence ends to replay.
